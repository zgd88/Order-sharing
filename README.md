# 同城教培撮合与拼团小程序 — MVP 第一期

依据《同城教培撮合与拼团小程序 PRD 大纲》实现的第一期功能：**拼好课（阶梯定价拼团）+ 老师资质认证 + 家长端参团 + PC 平台管理后台**。

## 项目结构

```
├── server/        Node.js + Express + SQLite 后端（端口 3000）
├── miniprogram/   微信原生小程序（单小程序，家长/老师双角色）
└── admin/         PC 管理后台（Vue3 + Element Plus + Vite，端口 5173）
```

## 快速启动

### 1. 后端（需要 Node.js ≥ 22.5，推荐 24）

```bash
cd server
npm install
npm start                 # 启动 http://localhost:3000
```

首次启动自动建表并创建管理员。灌入演示数据（可选）：

```bash
npm run seed              # 3位老师(2已认证/1待审核)、8位家长、4门课程、1条Banner
npm run seed -- --reset   # 清空业务数据后重建
```

### 2. 小程序

1. 用**微信开发者工具**导入 `miniprogram/` 目录（测试号即可）
2. 详情 → 本地设置 → 勾选「不校验合法域名」（开发期后端为 localhost）
3. 编译运行：登录页选择家长/老师身份即可体验

- 接口地址在 `miniprogram/utils/request.js` 的 `BASE_URL`，真机调试需改为电脑局域网 IP
- 演示老师账号：登录时选老师身份，用户名随意（开发期按设备标识自动登录）。体验"已认证老师"流程可用设备标识 `demo_teacher_1`/`demo_teacher_2`（需先在 request 调试或直接用演示数据对应 openid，即小程序登录接口传 deviceId=demo_teacher_1）

### 3. PC 管理后台

```bash
cd admin
npm install
npm run dev               # 打开 http://localhost:5173
```

登录账号：**admin / admin123**（后端种子自动创建）

## 已实现功能

### 家长端（小程序）
- 拼好课大厅：Banner 轮播、科目/年级筛选、**省→市→区县三级联动地区选择**（城市即可确定，区县可选，全国 31 省 341 市数据内置）、按距离排序（Haversine）
- 课程详情：阶梯价目表（高亮当前档）、拼团进度、"再邀 X 人全员降至 Y 元"提示
- 参团：按当前档价入团，人数上一档自动给先前家长生成退差记录
- 我的参团：成团进度、当前应付价、退款台账明细
- 分享海报：canvas 绘制（小程序码为占位，接入微信后替换）
- **找老师发单**：发布需求（科目/年级/课时费/电话/地图选点），"课程"页可切换查看我的需求
- **需求详情**：收到简历列表（老师头像/教龄/学历/专业/自荐），"选择该老师"二次确认后锁单，其余简历置灰提示已停止招募

### 老师端（小程序）
- 资质认证：实名 + 身份证 + 电话 + 教师资格证/学历证上传 + 学历/专业，平台审核（通过/驳回+原因）
- 发布拼好课：科目/年级/时间/地点/大纲 + 阶梯定价设置器（1-5 档，服务端校验）
- 我的课程：报名进度、家长名单（第几位报名/入团价/当前价）
- 收益明细：课程收入汇总（预留平台 5% 抽成展示）
- 取消课程：家长自动收到全额退款记录
- **需求大厅**：查看家长找老师订单（隐私脱敏：无电话、地址仅到区/街道），投递简历（一单一投）
- **我的投递**：待处理/已选中/已失效状态跟踪
- **站内信**：订单被接走、被选中、订单关闭等通知

### 平台后台（PC Web）
- 数据看板：用户/老师/课程/参团/发单/待跟进锁定单统计
- 老师资质审核：证件查看、学历专业、通过/驳回
- **订单管理（发单撮合）**：状态筛选、锁定订单客服工作台（家长电话+老师电话+地址+课时费）、客服跟进备注
- 课程管理：状态筛选、参团明细、退款台账、取消课程
- Banner 配置：图片上传、排序、启用/停用、跳转课程
- 用户管理：搜索、身份/认证状态

## 核心：阶梯定价引擎

位于 `server/services/tier-engine.js`，规则（对应 PRD 示例）：

- 家长**按加入后人数对应的阶梯价付款**（第 1 人付起步价 100 元；第 3 人加入时按 90 元直接付费）
- 人数每跨一档，系统为**先前已付款的成员**生成 `tier_diff` 退差记录（如 100→90 退 10 元）
- 达到成团人数 → `formed`；报名截止未达标 → `failed` 流局，退剩余应付金额（合计 = 入团实付）
- 老师/平台取消 → 同样全额退款；成团后开课时间结束 → `finished`
- 退款台账 `refund_records` 以 `(enrollment_id, event_key)` 幂等防重；模拟退款直接置 `paid`，
  接入微信支付后改为调微信退款接口再置 `paid`
- 事务 `BEGIN IMMEDIATE` + `join_seq` 唯一约束兜底并发报名
- 定时扫描（每分钟）+ 接口惰性检查双保险推进流局/完成

**验证**：`cd server && npm run test:engine`（56 项断言，覆盖阶梯退差/成团/流局/取消/满员/幂等）

### 撮合锁单引擎

位于 `server/services/demand.js`，规则（对应需求文档的并发与隐私要求）：

- 家长发单 → `recruiting`；老师投递（一单一投，UNIQUE 约束）→ 家长查看简历列表
- 家长选择老师：`BEGIN IMMEDIATE` 事务内**校验订单仍为 recruiting**，立即置 `locked`，
  其他投递全部 `invalid` + 给每位投递老师发站内信"订单已被接走"，被选老师收到"已被选中"通知；
  并发双锁第二笔必然失败（状态校验 + 409）
- 家长关闭订单：投递失效 + 站内信通知
- **隐私**：老师端接口永不返回 `phone`/`address`，仅返回 `addressDisplay`（脱敏到区/街道，
  `maskAddress` 去掉门牌号/栋/单元/室）；家长电话仅后台可见

**验证**：`cd server && node scripts/test-demand-lock.js`（35 项断言，覆盖脱敏/重复投递/锁单/双锁 409/失效通知/关闭）

## 开发期约定

- 登录：小程序 `wx.login` 预留，开发期用 deviceId 生成 `mock_xxx` openid
- 图片：上传到 `server/uploads/`，通过 `/uploads/xxx` 访问
- 数据库：`server/data/peixue.db`（node:sqlite 内置模块，零依赖）；删除该文件可重置全部数据
- **位置选择**：所有表单统一走"选择地图位置"页（高德搜索 + 微信地图点选），位置一行展示
  - 高德 POI 搜索需在 `server/config.js` 填入 `amapKey`（或环境变量 `AMAP_KEY`），申请地址：https://console.amap.com（Web服务类型）
  - 未配置 Key 时搜索会提示，可先用"在地图上选点"（wx.chooseLocation，无需 Key）
  - 搜索/选点后自动解析省份与"市+区县"用于首页筛选，表单中不再单独填写
